# Security Policy

## Supported Versions

This repository is a personal academic website. Security updates are provided only for the latest version on the `main` branch.

| Version | Supported |
|---------|-----------|
| `main`  | ✅        |

Older commits, branches, and archived versions are not actively supported.

## Reporting a Vulnerability

Please report suspected security issues privately by emailing:

**ali.niazi@ucalgary.ca**

Please include:

- The affected page, file, or URL
- A description of the issue
- Steps to reproduce it
- Any relevant screenshots or supporting details

Please do not disclose the issue publicly until it has been reviewed.

I will acknowledge reports within 7 days and will provide updates as the issue is investigated. This repository is a static academic website, so reports involving exposed credentials, private information, malicious scripts, or unsafe deployment configuration will be prioritized.
